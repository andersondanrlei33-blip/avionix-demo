# Avionix Demo

Landing page/jogo demonstrativo inspirado na estrutura pública do site fornecido pelo usuário.

## O que está incluído

- Layout responsivo em HTML/CSS puro
- Animação do avião e multiplicador em JavaScript
- Créditos virtuais salvos no `localStorage`
- Campo de parada automática
- Histórico de multiplicadores
- Modal de login/cadastro local de demonstração
- Sem backend, sem Pix, sem depósitos, sem saques e sem dinheiro real

## Como rodar

Você pode abrir `index.html` diretamente no navegador. Para desenvolvimento, também pode usar um servidor local, por exemplo:

```bash
python -m http.server 8000
```

Depois abra `http://localhost:8000`.

## Arquivos

- `index.html` — estrutura da página
- `style.css` — visual e responsividade
- `script.js` — interação e lógica da demo

## Observação

Para transformar em um produto com usuários reais, recomenda-se implementar backend, autenticação segura, banco de dados e validações apropriadas. Este projeto não implementa transações financeiras nem apostas com dinheiro real.
